# Impactalyst

Website des Leadership-Netzwerks **Impactalyst** (Hamburg) — „Leaders Shifting Culture".

Statische Single-Page-Site (HTML/CSS/JS, keine Frameworks), DSGVO-konform:
self-hosted Fonts, kein Tracking, keine externen CDN. Formular via Formspree.

**Live:** https://powerpeejay.github.io/impactalyst/

## Struktur
- `index.html` — Startseite (Hero · Manifest · Gründerin · Haltung · Beitreten)
- `impressum.html`, `datenschutz.html` — Rechtstexte
- `css/`, `js/`, `fonts/`, `assets/` — Assets

## Lokal testen
Einen beliebigen statischen Server im Repo-Root starten, z. B.:
```
npx serve .
```
